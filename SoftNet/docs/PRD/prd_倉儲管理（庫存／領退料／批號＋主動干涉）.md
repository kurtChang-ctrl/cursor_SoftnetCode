# PRD｜倉儲管理模組（庫存／領退料／批號 + 主動干涉）

> 本文件定義 Softnet MES「倉儲管理模組」之產品需求。
> 核心目標：**讓庫存數據成為可被信任、可被主動修正的生產基礎。**

---

## 1. 模組定位

### 1.1 角色
- 管理原料、在製品、成品庫存
- 支援製造派工的即時用料需求
- 與主動干涉引擎聯動，避免錯料、缺料、假庫存

### 1.2 與其他模組關係
- 上游：排程管理（APS）
- 平行：製造管理（派工／報工）
- 下游：出貨／成品倉
- 橫向：主動干涉引擎（R-04, R-05, R-07, R-13）

---

## 2. 使用角色（User Roles）

| 角色 | 行為 |
|---|---|
| 倉管 | 收料 / 發料 / 盤點 |
| 操作員 | 領料 / 退料 |
| 生管 | 庫存干涉 / 強制調撥 |
| 管理者 | 儲位 / 批號 / 規則 |

---

## 3. 核心設計原則

1. **庫存不是靜態數字，而是流動狀態**
2. **批號與到料日是排程與干涉依據**
3. **系統可自動補齊缺失行為**

---

## 4. 核心流程（高階）

```text
收料
 → 入庫（批號 / 到料日）
   → 庫存可用
     → 生產領料
       → 生產使用
         → 退料 / 入庫
```

---

## 5. 功能需求（Functional Requirements）

### F-01 收料 / 入庫管理
- 支援來源：
  - 採購單
  - 外加工回收
- 入庫資訊：
  - 料號
  - 批號（BarCode）
  - ArrivalDate
  - 數量

---

### F-02 庫存管理（即時）
- 區分：
  - 可用庫存
  - 在製庫存
  - 安全庫存

---

### F-03 生產領料（人工 / 自動）
- 來源：
  - 工單派工
  - 主動干涉（R-05）

---

### F-04 生產退料 / 補料
- 條件：
  - 工單結束或異常

---

### F-05 批號與到料日管理
- 每批料必須具備：
  - BarCode
  - ArrivalDate
- 作為：
  - FIFO
  - 排程計算
  - 干涉判斷依據

---

### F-06 已派工未領料干涉（R-07）
- 行為：
  - 警示
  - 或自動建立領料單

---

### F-07 安全存量與移轉合理性檢查（R-13）
- 條件：
  - 在製 + 再途 + 移轉量異常
- 行為：
  - 阻止移轉
  - 建立警示

---

### F-08 缺料自動補齊（R-04）
- 條件：
  - 可用量 < 安全存量
- 行為：
  - 觸發採購 / 外加工

---

## 6. 與主動干涉引擎對照

| Rule | 功能 |
|---|---|
| R-04 | 安全存量補單 |
| R-05 | 自動領料 |
| R-07 | 派工未領料 |
| R-13 | 移轉合理性 |

---

## 7. 資料模型（概要）

### 7.1 核心 Entity
- Stock
- StockTransaction
- MaterialIssue
- MaterialReturn
- BarCode_TMP
- ArrivalDate

---

## 8. 非功能需求

- 即時性：庫存變動 < 5 秒
- 正確性：禁止負庫存
- 可追溯：批號全程追蹤

---

## 9. MVP 與 Phase 2

### MVP
- 基本入庫 / 領退料
- 主動干涉關鍵 Rule

### Phase 2
- 自動倉儲設備整合
- 即時庫存看板
